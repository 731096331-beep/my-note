#等保2.0的一些理解


## 先搞清楚等保2.0是什么

等保的全称是"网络安全等级保护"，2.0是相对于2007年那套标准（大家习惯叫1.0）来说的。
核心依据是《网络安全法》第21条，法律层面把等级保护定下来了。
2019年5月发布了三个新标准——GB/T 22239（基本要求）、GB/T 28448（测评要求）、
GB/T 25070（安全设计技术要求），同年12月1日正式实施，2.0时代就是从这开始的。

## 跟1.0比，变化主要在哪

**名字的变化** “等保2.0”将原标准的“信息系统安全等级保护”改为“网络安全等级保护”，
例如《信息系统安全等级保护基本要求》改为《网络安全等级保护基本要求》。从“信息”到“网络”，
由此可见，对象范围一下子就宽了。

**法律依据** 从等保1.0的效力位阶为规章、行政法规到等保2.0的效力位阶为法律，由此可见它
的重要性。

**保护对象的变化** 等保1.0定义等级保护对象为：信息安全等级保护工作直接作用的具体信息
和信息系统；等保2.0定义等级保护对象为：定级对象随信息技术发展变化，由信息系统变更为网络，
保护对象全覆盖，领域全覆盖。包括基础信息网络、云计算平台/系统、大数据应用/平台/资源、
物联网、工业控制系统和采用移动互联技术的系统等。他的保护对象便宽泛了许多

**等级评定** 等保2.0沿用了传统等级保护的“5个等级”，但是整体定级更加严格，等保2.0系统
定级必须经过专家评审和主管部门审核，才能到公安机关备案；同时测评周期也进行了调整，
三级以上系统每年开展一次测评，修改了原先四级系统每半年进行一次等保测评的要求。

**内容变化** 等保1.0只有安全要求，而等保2.0变为安全通用要求和安全扩展要求，与此同时
等保2.0针对云计算、移动互联、物联网和工业控制系统提出了安全扩展要求

**整体框架变化** 技术要求从1.0的五个层面（物理安全、网络安全、主机安全、
应用安全、数据安全）调整成：安全物理环境、安全通信网络、安全区域边界、
安全计算环境、安全管理中心。我个人的理解是，1.0的分法偏"按设备类型分"，
2.0偏"按安全能力域分"——特别是"安全管理中心"这个层面是新东西，强调对
全网安全设备的集中管控，以前设备各管各的、日志各存各的，现在要求统一
监测、统一审计。

**可信验证** 2.0在几个关键节点（通信、边界、计算环境）都写了
可信验证的要求，方向是往可信计算体系上引。不过说实话，这条目前落地的
程度参差不齐，很多测评现场就是看看有没有相关的机制设计，算是方向性的要求。

**测评结论变化** 1.0的结论基本就是符合、基本符合、不符合三档，很粗。
2.0改成了优、良、中、差四档，打分制。"优"的门槛相当高——综合得分90以上
且不能有中高风险项，实务里能拿"优"的系统凤毛麟角，大部分单位的目标
就是保"良"。

总体来说，等级保护的基本要求、测评要求和设计技术要求统一框架，构建“
一个中心，三重防护”的安全体系；通用安全要求+新型应用安全扩展要求，
将云计算、移动互联、物联网、工业控制系统等列入了标准规范。
